# NASAH Realestate — Static Animated Website

Stack: **Next.js 14 (App Router)**, **TypeScript**, **TailwindCSS**, **Framer Motion**, **Three.js (@react-three/fiber + drei)**.

## Run locally
```bash
npm i
npm run dev
```

## Static export
```bash
npm run build
# static files in /out
```

## Features
- Hero section with animated 3D blob and big typography
- Scroll-animated orange line using `framer-motion` (`pathLength`)
- Properties grid and property details pages
- Menu overlay with curved line, contacts & social
- **3 color themes** toggle (Orange, Oceans, Forest)
- Clean `.gitignore`
